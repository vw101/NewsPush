# 阿里云函数计算 (FC 3.0) 飞书转接与定时早报网关部署指南

本目录下的 `index.js` 是专为**阿里云函数计算（Function Compute 3.0 / 2.0）**打造的轻量级双向点火转接器。

---

## 🌟 核心优势

1. **国内直连，彻底杜绝 3 秒超时**：部署在阿里云大陆机房（杭州/上海等），与飞书服务器同处国内骨干网，Challenge 校验在 **50 毫秒内**秒通。
2. **双模同时支持（回调 + 定时）**：
   - **飞书事件回调**：群内 `@机器人 早报`，200ms 内群内即时回显并唤醒 GitHub Actions。
   - **定时早报推送**：支持阿里云 FC 定时触发器（Timer Trigger / Cron），每天北京时间 09:00 准时唤醒云端容器，彻底规避 GitHub 原生 Cron 延迟丢单问题。
   - **HTTP 手动/外部点火**：支持访问 `/cron` 或 `/timer` 一键触发早报生成与推送。
3. **极致轻量**：纯原生 Node.js，零任何第三方 npm 依赖包，冷启动耗时 <10ms。
4. **安全注入**：通过阿里云控制台的环境变量（Environment Variables）注入敏感凭据，代码中无任何明文 Secret。
5. **架构兼容**：无论在控制台创建的是「Web 函数」还是「事件函数」，均可自动识别适配，开箱即用。

---

## 🚀 部署配置指引（耗时约 3 分钟）

### 第一步：在阿里云创建函数

1. 登录 [阿里云函数计算 FC 控制台](https://fcnext.console.aliyun.com/)。
2. 地域建议选择：**华东2（上海）** 或 **华东1（杭州）**。
3. 点击 **创建函数**：
   * **函数类型**：选择 **Web 函数**（推荐）或 事件函数
   * **基本设置**：
     * 函数名称：`feishu-news-relay`
     * 运行环境：**Node.js 18** 或 **Node.js 20**
     * 内存规格：128 MB（最低配置即可，极其节省成本）
   * **触发器设置**：
     * 请求处理程序类型：HTTP 触发器
     * 认证方式：**无需认证 / Anonymous**（必须选无需认证，飞书才能 POST 回调）
4. 点击页面右下角 **创建**。

---

### 第二步：粘贴代码并配置环境变量

1. **部署代码**：
   * 进入函数详情页，点击 **代码** 标签页。
   * 打开 `index.js`，将本项目 `aliyun_fc/index.js` 的全部内容粘贴覆盖进去。
   * 点击代码编辑器上方的 **部署代码（Deploy）**。

2. **配置环境变量**：
   * 在函数详情页，点击 **配置** ➔ **环境变量** ➔ 点击 **编辑**。
   * 添加以下 5 个键值对：

| 变量名 (Key) | 变量值 (Value) | 说明 |
| :--- | :--- | :--- |
| `GITHUB_REPO` | `vw101/NewsPush` | 你的 GitHub 仓库地址 |
| `GITHUB_TOKEN` | `<YOUR_GITHUB_PERSONAL_ACCESS_TOKEN>` | 用于唤醒 GitHub Actions 的 PAT 密钥 (需具备 repo/workflow 权限) |
| `FEISHU_APP_ID` | `cli_aa133f279a79dbb4` | 飞书开放平台应用 App ID |
| `FEISHU_APP_SECRET` | `<YOUR_FEISHU_APP_SECRET>` | 飞书开放平台应用 App Secret |
| `FEISHU_CHAT_ID` | `oc_41144adb848366fd8a1ac77bc8d40d7d` | 定时早报默认推送的目标飞书群 Chat ID |

   * 点击 **保存**。

---

### 第三步：配置定时触发器（实现 09:00 定时推送）

1. 在阿里云函数详情页，点击 **「触发器管理」** 标签页。
2. 点击 **「创建触发器」**：
   * **触发器类型**：选择 **定时触发器 (Timer)**
   * **触发器名称**：`daily-9am-push`
   * **触发方式**：选择 **Cron 表达式**
   * **Cron 表达式**：
     ```text
     0 0 1 * * *
     ```
     *(注：Cron 为 UTC 时间，UTC 01:00 对应北京时间每天上午 09:00。如需 09:05 可填 `0 5 1 * * *`)*
   * **触发消息 (Payload)**：留空或填写 `{"action":"timer"}` 均可
3. 点击 **确定**。
   > 💡 阿里云定时触发器将严格在每天 09:00 准时打点调用函数，函数自动唤醒 GitHub Actions 生成并推送当日新闻。

---

### 第四步：在飞书后台绑定触发网址（实现群内 @机器人 实时响应）

1. 回到阿里云函数详情页，找到并复制分配给你的 **公网访问地址（URL）**，形如：
   ```text
   https://feishu-news-relay-xxxx.cn-hangzhou.fcapp.run
   ```
2. 打开 [飞书开放平台 (open.feishu.cn)](https://open.feishu.cn/app) ➔ 进入你的 `AI新闻人` 自建应用：
   * 左侧菜单点击 **「事件与回调」**。
   * 订阅方式勾选：**「将事件发送至 开发者服务器」**。
   * 将复制的阿里云 `https://...fcapp.run` 地址粘贴进 **「请求网址」**。
   * 点击 **保存**（**飞书将在 50 毫秒内验证通过！**）。
3. 左侧点击 **「版本管理与发布」** ➔ 点击 **「创建版本」** ➔ **「申请发布」**。

## 🎯 效果验证与多渠道触发

### 1. 每日定时自动送达
每天早晨 09:00，阿里云定时触发器准时点火，无需任何人工操作，飞书群内准时收到精炼卡片。

### 2. 飞书群内即时互动
在飞书群里发送：
`@AI新闻人 早报`
1. 机器人在 200 毫秒内会在群里即时反馈：
   > 🤖 *收到指令！正在全网检索近3天 AI 重磅动态、实战 Skill、前沿突破与安全资讯，请稍候约 1 分钟...*
2. GitHub Actions 在后台完成抓取与精炼，自动将全量 4 大板块的新闻卡片推送到群内。

### 3. 浏览器 / HTTP 外部一键触发
在浏览器直接访问：
```text
https://feishu-news-relay-xxxx.cn-hangzhou.fcapp.run/cron
```
即可立即手动触发一次完整的 GitHub Actions 早报生成与群推送流程。
